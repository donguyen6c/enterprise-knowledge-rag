# Tên đề tài

Xây dựng hệ thống quản lý tri thức đa tổ chức tích hợp chatbot RAG,
tìm kiếm ngữ nghĩa và kiểm soát truy cập theo vai trò.

# Mục tiêu

Xây dựng nền tảng cho phép doanh nghiệp hoặc tổ chức quản lý tài liệu
nội bộ và cung cấp chatbot hỏi đáp dựa trên các tài liệu được tải lên.

# Đối tượng sử dụng

- Quản trị viên hệ thống
- Quản trị viên tổ chức
- Nhân viên tổ chức

# Công nghệ

- Backend: Django REST Framework
- Frontend: Next.js
- Database: PostgreSQL + pgvector
- Authentication: JWT
- RAG: Embedding + Semantic Search + LLM

# Dữ liệu thử nghiệm

Các tài liệu công khai của Trường Đại học Mở TP.HCM, bao gồm quy chế
đào tạo, học phí, thực tập và xét tốt nghiệp.
